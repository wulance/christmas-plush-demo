制作流程

从草图到玩偶的四个步骤

  1. 1. 草图

    我们画出角色，并与你们确认性格、比例和颜色。

  2. 2. 版型

    草图会做成缝制版型，并用白坯布测试立体造型。

  3. 3. 面料与样品

    我们选定面料、对好颜色，并缝制样品供你们确认。

  4. 4. 生产与质检

    我们缝制、填充、做安全测试并检查每一件。通常在样品确认后需要 15–25 天（演示周期，非承诺交期）。

常见问题

起订量是多少？

企业定制玩偶起订 50 件。圣诞系列和照片生成玩偶可以按件询价（演示说明）。

定制一只玩偶要多久？

第一版电子设计约 2–3 天，实物样品约 7–10 天。样品确认后的生产约 15–25 天，另外加上运输时间（演示周期，非承诺交期）。

这些玩偶对儿童安全吗？

文案中提到的 EN71、ASTM F963 和 CPSIA 仅为占位示例，并不是已取得的真实认证。面向幼儿时会使用刺绣眼睛，而不是硬质配件。（请替换为你们的真实认证信息。）

可以寄送到其他国家或地区吗？

演示站点展示了多种目的地的参考时效。具体发货时间和节日截止日请以确认后的说明为准，页面数字不是承诺送达。

有玩偶创意吗？

把草图、logo 或照片发给我们。正式流程里，我们会在 3 个工作日内回复电子设计稿（本页为演示，不会发送或收款）。
